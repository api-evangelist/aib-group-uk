# AIB Group (UK)

> AIB Group (UK) p.l.c. is a UK bank incorporated in Northern Ireland, trading as Allied Irish Bank (GB). As one of the CMA9 banks mandated under the UK Open Banking order, it runs a public developer portal publishing UK Open Banking (OBIE) APIs: a public Open Data API (v2.2) and a FAPI-secured Read/Write family (Account Information, Payment Initiation, Confirmation of Funds, Variable Recurring Payments, Event Notifications) under OAuth2/OIDC consent with PSD2 strong customer authentication and Dynamic Client Registration.

## APIs

- [Open Data API (v2.2)](https://developer.aibgb.co.uk/open-data-v2-2-gb/apis): Public, unauthenticated product/branch/ATM reference data. Base: https://openapi.aibgb.co.uk/open-banking/v2.2
- [Accounts Information API (AIS v4.0)](https://developer.aibgb.co.uk/accounts-information-v4-0-gb/apis): Account details, balances, transactions, standing orders, direct debits, statements. FAPI-secured.
- [Payments Initiation API (PIS v4.0)](https://developer.aibgb.co.uk/payments-initiation-v4-0-gb/apis): Domestic and scheduled payment initiation. FAPI-secured.
- [Confirmation of Funds API (CBPII v4.0)](https://developer.aibgb.co.uk/confirmation-funds-v4-0-gb/apis): Yes/no funds-available check. FAPI-secured.
- [Variable Recurring Payments API (VRP v4.0)](https://developer.aibgb.co.uk/variable-recurring-payments-v4-0-gb/apis): Sweeping and TPP-initiated recurring payments under one consent. FAPI-secured.
- [Credit Cards Information API](https://developer.aibgb.co.uk/credit-cards-information-gb/apis): Credit card account information under Open Banking consent.
- [Dynamic Client Registration API (DCR v3.2)](https://developer.aibgb.co.uk/dynamic-client-registration-api-v3-2-gb/apis): Programmatic client registration with OBIE/eIDAS certificates.
- [Event Notification Subscription API (v4.0)](https://developer.aibgb.co.uk/event-notification-subscription-api-v4-0-gb/apis): Manage subscriptions to real-time event notifications.
- [Aggregated Event Polling API (v4.0)](https://developer.aibgb.co.uk/aggregated-event-polling-api-v4-0-gb/apis): Poll for aggregated event notifications.
- [FCA Service Metrics (BCA) API](https://developer.aibgb.co.uk/fca-service-metrics-bca-gb/apis): FCA-mandated service availability/performance metrics.
